# ⏳ Progression Obsession

**Progression Obsession** é um jogo incremental (*idle/clicker game*) imersivo desenvolvido em Python utilizando CustomTkinter e SQLite. Escolha sua classe, gerencie sua progressão e descubra os segredos da obsessão por evolução constante.

---

## 🎮 Funcionalidades

* **Sistema de Autenticação Local:** Crie sua "Alma" (conta) com dados persistidos de forma segura via SQLite.
* **Seleção de Classes:** Escolha entre 4 caminhos distintos para iniciar sua jornada, cada um com identidade visual própria:
  * 🏹 **Archer:** Foco em precisão, velocidade e multiplicadores críticos.
  * 🗡️ **Assassin:** Especializado em progressão explosiva e ganhos furtivos.
  * 🛡️ **Warrior:** Baseado em força bruta, resiliência defensiva e passivas estáveis.
  * 🔮 **Mage:** Canalizador de energia arcana para acelerar recursos.
* **Persistência Inteligente:** O sistema gerencia e atualiza o banco de dados automaticamente.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* **CustomTkinter** (Interface Gráfica Moderna)
* **SQLite3** (Banco de dados local)
* **Pillow (PIL)** (Manipulação de ícones e ativos visuais)

---

## 🚀 Como Executar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/SEU-USUARIO/progression-obsession.git](https://github.com/SEU-USUARIO/progression-obsession.git)
   cd progression-obsession

```

2. **Crie e ative um ambiente virtual (recomendado):**
```bash
python -m venv venv
# No Windows:
venv\Scripts\activate
# No Linux/Mac:
source venv/bin/activate

```


3. **Instale as dependências:**
```bash
pip install customtkinter pillow

```


4. **Execute o jogo:**
```python
python main.py

```
